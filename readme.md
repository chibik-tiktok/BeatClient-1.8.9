# BeatClient 1.8.9

Lightweight Minecraft 1.8.9 modpack focused on FPS, stability, and PvP.

## Features
- High performance with a minimal selection of mods
- Designed for Minecraft Java Edition 1.8.9
- Lightweight and simple
- Carefully selected mods for compatibility

## Performance
- Reported performance: up to 140 FPS in old PC
- Hardware and test conditions may affect results

## Installation
1. Download the release ZIP.
2. Go to your minecraft launcher and import this zip into a instance.
3. Install the required Minecraft version and dependencies.
4. Launch Minecraft 1.8.9.
